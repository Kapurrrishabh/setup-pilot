Set up a GitHub repo

SetupPilot downloads the repo, checks your tools and installs what it needs. It asks you before every command.

Only public repos on github.com, like https://github.com/pypa/sampleproject.

It must already exist. SetupPilot makes a new folder named after the repo inside it. You can type ~ for your home folder.

Safer for repos you do not fully trust. It is not a full sandbox here, because a container can reach this app. For a repo you do not trust at all, close this app and run setuppilot run <url> <folder> --docker in a terminal.

Docker is not running. Start Docker Desktop or run colima start, then press Check again.
